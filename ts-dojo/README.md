# TypeScript Dojo

Веб-дожо по системе типов TypeScript: **37 уроков, 64 эксперимента, 100 заданий**.
Компилятор **TypeScript 5.9.3 работает прямо в браузере** — тот же, что в `npm run check`.
Ошибки, их коды `TSxxxx`, полные тексты сообщений и выведенные типы настоящие.

## Что можно трогать

- **Тумблеры tsconfig** — `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`
  и остальные. Щёлкнул — и сразу видно, сколько ошибок держалось на одном флаге.
- **Проба типа** — ставишь курсор на любое имя, под редактором появляется выведенный тип.
- **Список ошибок** — с кодом, клик прыгает на строку.
- **Эксперименты** — варианты одного кода переключаются табами: сначала предсказываешь,
  потом открываешь разбор.
- **Задания** — стартовый код, «Проверить», подсказки тремя уровнями, решение отдельно.
  Проверяются и ошибки компилятора, и условия задания (например «без `as`»).

## Как это проверяется

Тексты уроков не могут разойтись с поведением компилятора — это проверяется автоматически.

- `src/data/compile.ts` — тот же TypeScript 5.9.3 в памяти, с теми же флагами, что в браузере.
- `scripts/sync-expectations.ts` — прогоняет каждый сниппет, проставляет фактические коды ошибок
  в поля `expect` / `starterExpect` и печатает диагностики, чтобы сверить их с написанным вердиктом.
- `src/data/__tests__/lessons.test.ts` — 496 тестов: каждый вариант эксперимента даёт заявленные
  коды, каждое эталонное решение проходит собственные проверки задания, каждый стартовый код
  падает ровно как обещано.

Валидатор ловил не опечатки, а неверные утверждения о компиляторе — около двадцати за курс.
Несколько примеров того, что пришлось переписать: `satisfies` не отменяет widening против `string`;
`keyof Record<string, V>` это `string`, а `keyof { [k: string]: V }` — `string | number`;
гомоморфность mapped type ломает не `as`, а переименование ключа; аннотация `out` не ловит
нарушение, записанное методом; в React 19 нет `MutableRefObject`, а `useRef<T>()` без аргумента
больше не компилируется.

## Команды

```bash
npm run dev      # приложение на localhost:5173
npm run build    # typecheck src + сборка
npm run check    # tsc --noEmit по консольным упражнениям в lessons/
npm test         # vitest: валидатор уроков + типовые тесты упражнений

node --experimental-strip-types scripts/sync-expectations.ts [фрагмент-slug]
```

## Устройство

`src/monaco/setup.ts` поднимает monaco точечными импортами: ядро редактора со всеми UI-фичами,
без 80 языков подсветки. Там же `applyFlags`, `getDiagnostics` и `getTypeAt` поверх настоящего
TypeScript language service, и регистрация типов React как extraLib.

Уроки — данные, не вёрстка: `src/data/types.ts` описывает `Lesson`, `Experiment`, `Task`.
Новый урок — файл в `src/data/lessons/` и строка в `src/data/index.ts`.

`lessons/NN-topic/` — консольная версия заданий первого урока с тестами на `expectTypeOf`.
