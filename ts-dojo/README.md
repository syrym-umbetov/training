# TypeScript Dojo

Веб-дожо по системе типов TypeScript. Компилятор **TypeScript 5.9.3 работает в браузере** —
это тот же компилятор, что в `npm run check`, а не подсветка синтаксиса и не заранее записанные
ответы. Ошибки, их коды `TSxxxx`, полные тексты сообщений и выведенные типы настоящие.

## Что можно трогать

- **Тумблеры tsconfig** — `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`
  и остальные. Щёлкнул — и сразу видно, сколько ошибок держалось на одном флаге.
- **Проба типа** — ставишь курсор на любое имя, под редактором появляется выведенный тип.
- **Список ошибок** — с кодом, клик прыгает на строку.
- **Эксперименты** — варианты одного и того же кода переключаются табами: сначала предсказываешь,
  потом открываешь разбор.
- **Задания** — стартовый код, кнопка «Проверить», подсказки по трём уровням, решение отдельно.
  Проверяются и ошибки компилятора, и условия задания (например «без `as`»).

## Команды

```bash
npm run dev      # приложение на localhost:5173
npm run build    # typecheck src + сборка
npm run check    # tsc --noEmit по консольным упражнениям в lessons/
npm test         # vitest run --typecheck
```

## Две версии одних заданий

`src/data/lessons/` — то, что видно в браузере. `lessons/NN-topic/` — те же задания файлами,
с тестами на `expectTypeOf` и `@ts-expect-error`, чтобы гонять из консоли.

## Как устроено

`src/monaco/setup.ts` поднимает monaco с точечными импортами: ядро редактора со всеми UI-фичами,
но без 80 языков подсветки, которые тянет вход по умолчанию. Там же — `applyFlags`,
`getDiagnostics` и `getTypeAt` поверх настоящего TypeScript language service.

Уроки — данные, не вёрстка: `src/data/types.ts` описывает `Lesson`, `Experiment`, `Task`.
Чтобы добавить урок, достаточно нового файла в `src/data/lessons/` и строки в `src/data/index.ts`.
